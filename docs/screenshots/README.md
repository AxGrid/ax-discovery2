# Screenshots

Drop PNGs in this directory using these filenames so they appear in the main `README.md`:

| Filename             | What it should show |
|----------------------|---------------------|
| `services.png`       | The main `Services` page — list/grid of registered services with up/down counts and visibility badges |
| `service-detail.png` | A single service with its instances, the per-interface pills (some red), and the `Check` button result |
| `instance-editor.png`| The instance editor open, showing the liveness-check selector and the per-interface health-URL input |
| `users.png`          | The admin Users page with a couple of accounts |
| `audit.png`          | The Audit log table with a few entries |
| `cluster.png`        | The Cluster page showing one or two members and the join form |
| `login.png`          | The login screen (light or dark) |

Recommended size: ~1600px wide. PNG, no JPEG.

Both light and dark theme are fine — pick whichever looks tidier. Keep
real tokens / URLs out of the frame.
